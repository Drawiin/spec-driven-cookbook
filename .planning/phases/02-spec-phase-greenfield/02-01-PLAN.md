    Module docstring: "tool-validate-spec — Check that SPEC.md exists and has status: approved. Exit 0: approved. Exit 1: not approved or file not found (message to stderr)."

    Imports: pathlib, sys (stdlib only — no yaml, no tomllib, no third-party imports).

    SPEC_CANDIDATES constant: list of pathlib.Path objects — [Path(".planning/SPEC.md"), Path("SPEC.md")] — searched in order.

    parse_frontmatter(text: str) -> dict function:
    - Returns {} if text does not start with "---"
    - Finds closing front-matter boundary with text.find("\n---", 3); returns {} if -1
    - Extracts block between the two "---" markers using text[3:end].strip()
    - Iterates block.splitlines() (not split("\n") — CRLF safety)
    - Skips blank lines and lines starting with "#"
    - For lines containing ":", calls line.partition(":") to split key and value; strips whitespace from both
    - Returns dict of parsed key→value pairs

    main() function:
    - Iterates SPEC_CANDIDATES; breaks on first candidate where .exists() is True; spec_path remains None if none found
    - If spec_path is None: prints to sys.stderr "ERROR: SPEC.md not found in .planning/ or project root.\nRun /spec-phase first to create and approve a spec." then calls sys.exit(1)
    - Reads spec_path.read_text(encoding="utf-8"); calls parse_frontmatter
    - If result dict is empty: prints to sys.stderr "ERROR: {spec_path} has no valid YAML front-matter.\nExpected format:\n---\nstatus: approved\nversion: 1\ndate: YYYY-MM-DD\n---" then sys.exit(1)
    - Gets fm.get("status", ""); if != "approved": prints to sys.stderr "ERROR: SPEC.md status is '{status}' — must be 'approved' before planning.\nRun /spec-phase and complete the approval gate." then sys.exit(1)
    - On success: prints "✓ SPEC.md approved (version {fm.get('version','?')}, {fm.get('date','?')})" then sys.exit(0)

    if __name__ == "__main__": main()
