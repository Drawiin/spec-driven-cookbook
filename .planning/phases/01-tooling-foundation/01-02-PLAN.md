    build_tree(root: pathlib.Path, patterns: list, depth: int = 3, prefix: str = "") -> list: if depth == 0 return []. Sort entries with dirs before files using key=lambda p: (p.is_file(), p.name). Filter out excluded entries. For each entry: use "└── " connector if last entry else "├── "; append f"{prefix}{connector}{entry.name}".     git_summary(root: str) -> str: define inner run(args) that calls subprocess.run(["git", "--no-pager"] + args, stdout=subprocess.PIPE, stderr=subprocess.PIPE, text=True, timeout=10, cwd=root); return r.stdout.strip() if returncode == 0 else "". Get branch via run(["rev-parse", "--abbrev-ref", "HEAD"]). If branch is empty string, return "_Not a git repository._\n". Get log via run(["log", "--oneline", "-10"]). Get status via run(["status", "--short"]). Build markdown: "**Branch:** {branch}", blank line, "**Recent commits:**", code fence, log, closing fence. If status non-empty, append: blank line, "**Uncommitted changes:**", code fence, status, closing fence. Return joined string.

    find_entry_points(root: pathlib.Path, max_files: int = 5) -> list: iterate ENTRY_POINT_CANDIDATES; check if root/candidate exists and is_file(); append to found list; stop when len(found) >= max_files; return found.

    preview_file(path: pathlib.Path, max_lines: int = 20) -> str: read first max_lines lines via path.read_text(encoding="utf-8").splitlines()[:max_lines]; join and wrap in code fence; handle UnicodeDecodeError and OSError by returning "_(binary or unreadable)_" instead of raising.

    main(): set up argparse with --root (default str(pathlib.Path.cwd()), type=str) and --depth (default 3, type=int). Resolve root: root = pathlib.Path(args.root).resolve(); cwd = pathlib.Path.cwd().resolve(); assert root == cwd or cwd in root.parents or root in cwd.parents — on failure print error and sys.exit(1). Load gitignore patterns. Build and print the four sections separated by "---":
    - Section 1 "## Directory Tree": build_tree result joined with newlines; wrap in code fence
    - Section 2 "## Dependencies": look for pyproject.toml, package.json, requirements.txt in priority order; read first one found and print in code fence; if none found print "_(none detected)_"
    - Section 3 "## Git Summary": call git_summary(str(root))
    - Section 4 "## Key Files": find_entry_points and preview_file for each; if none found print "_(no entry points detected)_"
    Always sys.exit(0) at end (context-builder never fails fatally — it degrades gracefully).

    if __name__ == "__main__": main()

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer → context_builder.py via --root arg | --root path is user-supplied; could attempt traversal outside project root |
| context_builder.py → git subprocess | Subprocess calls to git; args are hard-coded constants, not user-supplied |
| context_builder.py → filesystem reads | Reads .gitignore, dependency files, entry-point files from resolved root |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | --root CLI argument in main() | mitigate | Resolve to absolute path with pathlib.Path.resolve(); assert root is cwd or within parent/child of cwd before any filesystem read; sys.exit(1) on violation |
| T-02-02 | Tampering | git subprocess calls in git_summary() | mitigate | Explicit arg arrays only — ["git", "--no-pager", "log", "--oneline", "-10"]; no user input interpolated into git args; no shell=True; verified in acceptance criteria |
| T-02-03 | Denial of Service | git subprocess timeout | mitigate | timeout=10 on all subprocess.run() calls in git_summary(); graceful string return on TimeoutExpired |
| T-02-04 | Information Disclosure | key file previews in stdout | accept | Only reads first 20 lines of well-known entry-point files; developer controls which files are in their own project; no credential scanning |
| T-02-SC | Tampering | supply chain | accept | No new packages installed in this plan; pytest already installed in Wave 1 |
</threat_model>
