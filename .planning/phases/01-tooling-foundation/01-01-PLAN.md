    Create mise-en-place/tool-env-check/env_check.py. Imports: os, shutil, subprocess, sys. Keep file under 120 lines.

    CHECKS list (module-level constant): list of (name_str, cmd_list) tuples for four checks — ("git", ["git", "--version"]), ("python3", ["python3", "--version"]), ("bun/node", ["bun", "--version"]), ("cursor", ["cursor", "--version"]). The bun/node entry is handled specially in run_check.

    run_check(name: str, cmd: list) -> tuple[str, str]: returns (status_char, detail_str) where status_char is "✓" or "✗". Special cases: (a) if name == "cursor", first try os.environ.get("CURSOR_TRACE_ID") — if set, return ("✓", "cursor (detected via CURSOR_TRACE_ID)") immediately without subprocess; (b) if cmd[0] is "bun" and shutil.which("bun") is None, try shutil.which("node") and run ["node", "--version"] instead; if neither found return ("✗", "bun/node: not found in PATH"). For all other checks: if shutil.which(cmd[0]) is None return ("✗", f"{cmd[0]}: not found in PATH"). Call subprocess.run(cmd, stdout=subprocess.PIPE, stderr=subprocess.PIPE, text=True, timeout=3) — do NOT use capture_output=True (Python 3.6 portability for TOOL-05). On TimeoutExpired return ("✗", f"{cmd[0]}: timed out"). On success, extract version from (r.stdout or r.stderr).splitlines()[0].strip() and return ("✓", version_str).

    main(): print "## Environment Check\n"; iterate CHECKS calling run_check for each; print f"  {status} {name}: {detail}" for each; track all_pass bool (False if any status is "✗"); print empty line; print "PASS" if all_pass else "FAIL — missing prerequisites above"; call sys.exit(0 if all_pass else 1).

    if __name__ == "__main__": main()

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer → env_check.py | Script invoked locally by the developer; no user-supplied arguments; no network surface |
| env_check.py → external binaries | Subprocess calls to git, python3, bun/node, cursor — PATH-resolved binaries |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | subprocess calls in run_check() | mitigate | Use explicit arg arrays (["git", "--version"]) — never string concatenation or shell=True; verified in acceptance criteria |
| T-01-02 | Denial of Service | subprocess.run() timeout | mitigate | timeout=3 on every subprocess call; prevents hang on slow binaries |
| T-01-03 | Information Disclosure | stdout output | accept | Script prints only binary version strings and PASS/FAIL; no secrets or credentials in scope |
| T-01-SC | Tampering | pytest dev install | accept | pytest is dev-only tooling, not shipped in mise-en-place/; legitimate package from PyPI; no SLOP/SUS packages in this phase |
</threat_model>
