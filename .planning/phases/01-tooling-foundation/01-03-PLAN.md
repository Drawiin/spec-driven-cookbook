<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer → planning_scaffold.py via --root arg | --root path is user-supplied; could attempt traversal outside project root |
| developer → write-artifact via artifact arg | artifact path is user-supplied; could attempt "../" traversal to escape .planning/ |
| planning_scaffold.py → filesystem reads/writes | All operations must stay within resolved root and .planning/ subtree |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | --root CLI argument in main() | mitigate | Resolve to absolute path; assert within cwd before any operation; sys.exit(1) on violation (Shared Pattern 4) |
| T-03-02 | Tampering | artifact arg in write_artifact() | mitigate | Resolve candidate = (planning_root / artifact).resolve(); assert planning_root.resolve() in candidate.parents; sys.exit(1) on violation; verified by test_write_artifact_path_traversal_blocked |
| T-03-03 | Tampering | format-file target path | mitigate | Resolve file path before reading; only writes back to the same path that was read; no path-joining with user input beyond the file argument |
| T-03-SC | Tampering | supply chain | accept | No new packages installed; pytest from Wave 1; no SLOP/SUS packages |
</threat_model>
